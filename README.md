# CineTrack - Movie Management System

CineTrack is a Java web application for movie management built using the Spring MVC framework and Hibernate ORM.

## Technology Stack

- **Language:** Java 17
- **Framework:** Spring Web MVC 6.2.x
- **Persistence:** Hibernate ORM 6.5.2.Final (Jakarta Persistence 3.0)
- **Database:** PostgreSQL
- **Server:** Apache Tomcat 10.1
- **View Technology:** JSP
- **Build Tool:** Maven
